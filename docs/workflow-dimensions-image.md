# Workflow: Dimension Image

Goal: create a clean dimension graphic using real product imagery and readable measurement labels.

## Inputs

- Real product photo or cutout.
- Verified measurements.

## Steps

1. Confirm all measurements are correct.
2. Place the real product cutout on a clean canvas.
3. Add vector arrows, dimension lines, and labels.
4. Keep labels large and sparse.
5. Avoid clutter and decorative marks that compete with measurements.
6. Export the final PNG/JPG to `assets/output/`.

## Windows Note

Use native Inkscape manually or via CLI for SVG/PNG export. `inkmcp` is reserved for WSL/Linux Phase 2 because upstream currently depends on Linux D-Bus.
